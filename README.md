## 🛠️ Tecnologías Utilizadas

En este proyecto he utilizado estándares web limpios y modernos, priorizando el rendimiento, la accesibilidad y el diseño adaptativo (*responsive*):

- **HTML5:** Estructura semántica para mejorar la accesibilidad y SEO.
- **CSS3:** Estilos personalizados, diseño adaptativo (*Flexbox/Grid*) y tipografías personalizadas desde Google Fonts (*Bricolage Grotesque* e *IBM Plex Mono*).
- **Diseño Responsive:** Optimizado para la visualización en dispositivos móviles, tablets y ordenadores de escritorio.

## 🛠️ Instalación y Uso Local

Para clonar y visualizar este proyecto localmente en tu ordenador:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/HaelSel02/portfolio.git
   ```
2. **Navegar a la carpeta del proyecto:**
   ```bash
   cd tu-repositorio
   ```
3. **Abrir el archivo:**
   Abre el archivo `index.html` en tu navegador preferido o utiliza una extensión como *Live Server* en Visual Studio Code.
